# JurisCQAD

清理后的中文法律问答数据，共 **43,104** 条记录。

## 数据格式

`JurisCQAD_cleaned.jsonl.gz` 为无损 gzip 压缩文件，解压后为 UTF-8 JSON Lines，每行包含三个字符串字段：

| 字段 | 含义 |
| --- | --- |
| 问题内容 | 问题文本 |
| 原答案 | 数据集中标注的原始回答 |
| 错误答案 | 数据集中标注的错误回答 |

字段名反映原有标注，不代表已逐条核验法律正确性。

## 读取数据

只需 Python 标准库：

```python
import gzip
import json

with gzip.open("JurisCQAD_cleaned.jsonl.gz", "rt", encoding="utf-8") as f:
    records = [json.loads(line) for line in f]
```

## 清理说明

此版本经过脱敏、完全重复项去重、推广及无实质回答筛选、生成残留隔离，以及显式正误提示清理。标签清理阶段从 43,169 条记录中隔离 62 条并移除 3 条新增重复项，保留 43,104 条。

对两类答案应用相同的前缀清理规则，并清理明确暴露答案标签的说明。保留“虚构事实”等实质法律表述。详细计数及文件 SHA-256 见 `summary.json`。

## 数据划分

`split_groups.jsonl` 与数据文件逐行对应，包含 `group_id`、原始行号和清理后行号。同一组必须进入同一个数据分区。分组覆盖已识别的相同问题及部分字面近似问题，不保证识别全部语义改写。

划分脚本可直接读取压缩文件，也支持解压后的同名 JSONL。按需生成分区，例如：

```bash
python3 split_by_group.py --ratios 0.8 0.1 0.1 --out ./splits
```

此命令仅为使用示例；仓库不预设正式训练、验证和测试分区。划分脚本会校验数据哈希，并拒绝覆盖已有输出文件。

## 评测注意

- 不要将“原答案”“错误答案”字段名作为候选答案文本提供给模型。
- 使用匿名候选 A/B，随机交换顺序，将真值标签单独保存。
- 显式标签检测为零不代表消除了所有文风、长度或其他隐性线索。
- 本版本未经过领域专家逐条法律正确性审定，不能作为法律意见使用。

`record_manifest.jsonl` 提供行号溯源。含原始删除片段的审计日志及隔离记录未纳入此公开仓库。
